# Fit Images

Fit Images is an original FigCraft plugin that changes the scale mode of image fills across selected layers between Fit and Fill, without modifying layer dimensions or other paint properties.

## Commands

- `panel`: Opens the Fit Images settings panel.
- `apply`: Applies Fit or Fill mode to the selection or specified IDs.

## Permissions

- `image.fit`: Allowlisted engine command for atomic, undoable fill mode adjustments.
