# Image Trace

Trace bitmap images to editable vector paths or isolated masks.

## Features
- Bounded monochrome and color tracing (2 to 16 colors)
- Accurate silhouette tracing with hole detection
- Isolated mask output inside a clipped container frame
- Clean cell-boundary contour walker with deterministic budgets

## Usage
Select one or more (up to 16) image rectangles, open Plugins ▸ Image Trace…, adjust settings, and click Apply.
